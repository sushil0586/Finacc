# Core Finance Documentation Hub

Date: 2026-10-06

## Purpose

This folder contains the launch-grade operator documentation for Finacc core finance.

Use it when training users, supporting a launch, or checking what a finance operator should do before escalating an issue to engineering.

Scope:

- Settings and finance master readiness
- Sales and receivables
- Purchase and payables
- Vouchers
- Reports and accounting truth
- Bank reconciliation
- Assets
- Inventory and manufacturing finance links
- TDS, TCS, GST-TDS, GST reports, and GST reconciliation
- RBAC, email, and common troubleshooting

Out of scope:

- HRMS and Payroll launch certification
